# Public traffic research archive

This branch contains only research snapshots and aggregate model results derived from public DGCA/Ministry of Civil Aviation route counts. It must never contain user, booking, supplier, fare or credential data. The historical compilation comes from Vonter/india-aviation-traffic (ODbL 1.0); see the main branch's public/research/statsforecast-forward.md and source manifest for attribution, license, limitations, and clock warning. Branch contents and timestamps are not independently certified and can be changed by repository administrators.
